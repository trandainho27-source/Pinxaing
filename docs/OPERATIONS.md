# 不懂技术也能操作的使用说明

## 先花两分钟体验一次购买

1. 打开商城，选一件有库存的商品，点击「选购」。
2. 看商品介绍，点击「立即购买」。
3. 填测试联系方式，勾选购买协议，提交订单。
4. 点击「保存凭证」保存订单号和查询密钥，再点击「查看订单」。
5. 点击「模拟付款并交付」。页面会显示测试卡密，可以复制或下载。
6. 如要体验售后，点击「提交售后工单」，填写问题。

以上只在演示环境可用，不会扣款。示例库存售出后不会重复出售同一条内容，演示库存需要时可在后台导入新的测试内容。

## 进入后台

打开网站地址后加 `/admin`，演示站点击「进入演示管理后台」。前台不展示后台入口。正式站不提供这个演示入口：首次使用初始化令牌建立店主账号，之后使用自己的账号密码登录。

后台首页的「开店准备」按操作顺序指向相应页面。店主、运营和客服看到的菜单及可执行操作不同。

## 上架一件真实商品

1. 「商品分类」中新建分类，如软件授权、设计资源。
2. 「商品管理」→「新建商品」，选择分类，填写售价和说明。
3. 不同地区、套餐或授权年限分别建立商品，避免客户买错规格。
4. 图标可自动识别，也可手动选择 Telegram、X、Apple 等；仅在商品确实相关时使用对应标识。
5. 「卡密库存」选择这个商品，每行粘贴一条可以交付的授权码、链接或预约码，每次最多 30 条。
6. 返回商城，确认商品说明、价格、库存和图标正确。

库存内容会加密，后台不回显明文。相同商品的相同内容不会重复导入。待付款订单会临时锁定库存，超时后释放，已交付内容不会再次销售。

## 处理订单和售后

- 「订单管理」可按编号与状态筛选；点击订单号查看明细、付款和交付情况。
- 只有店主能确认线下收款。务必核对到账记录，并填写唯一流水号和依据；操作后立即交付库存。
- 客服可以看订单和回复售后，不能改价、导出卡密、管理员工或确认收款。
- 退款先在实际收款渠道完成，再在后台「登记退款」。登记不等于实际退款。
- CSV 导出的是当前页订单，不是整站数据库备份。
- 「操作日志」记录商品修改、库存导入、收款、退款和员工变动等关键操作。

## 店铺外观和团队

「站点设置」可修改品牌、标语、公告、客服指引、服务时间和协议。「员工与权限」可新增运营或客服账号，停用员工会立即撤销其登录会话。点击右上角头像可修改自己的密码。

本机订单记录会随浏览器清理而丢失，所以需要保存订单凭证。订单密钥相当于取货凭证，分享给别人会使别人能看到交付内容。
