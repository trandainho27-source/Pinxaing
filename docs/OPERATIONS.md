# 不懂技术也能操作的使用说明

## 先体验一次完整购买

1. 打开商城，选一件有货的商品，点击「立即购买」。
2. 购物车会显示商品金额和固定 **20 元邮费**。邮费没有取消按钮。
3. 收货人、收货地址和联系方式均可以不填。选择微信、支付宝或 USDT；目前这些接口均待接入。
4. 勾选购买协议并提交订单，点击「保存凭证」，保管订单号和查询密钥。
5. 创建成功页显示「加密通讯账号-极致的隐私与安全」及「付款后领取」，不会显示或提供复制账号内容。
6. 点击「查看订单」，再点击「模拟确认付款（不扣款）」。付款成功后账号内容才显示并可复制；演示内容不能登录 Telegram。没有物流单号时仍显示「未发货」。
7. 打开 `/admin`，进入演示管理后台，在「订单管理」中点击该订单号。
8. 如有需要，补充收货信息；切换「收货与配送」，点击「填写单号并确认发货」，输入测试单号（如 `TEST-SF-10001`）及原因，确认操作。
9. 返回商城重新查询该订单，看到「已发货」和对应单号；单号为空或为「无」时显示「暂无单号（未发货）」，没有物流轨迹。

演示操作不会实际收款、创建可登录账号或发送包裹。

## 上架真实商品

正式经营请使用独立正式环境。先在「商品分类」中新建类别，再在「商品管理」中填写名称、价格、说明和限购数量。不同尺寸、颜色等规格分别建商品。图片可填写 HTTPS 链接；没有图片时显示所选实体商品图标。

在「实体库存」选择商品、增加数量并填写入库原因。库存分可售、锁定、已售：客户下单锁定数量，确认收款转为已售；未付款订单取消或 30 分钟到期后恢复可售。减少库存只会减少可售数量，不会挪用已锁定或已售数量。

## 准备 Telegram 赠送账号

1. 店主打开「Telegram 赠送账号」。
2. 每行填写一个账号，竖线前是唯一账号标识，后面是交付给客户的登录信息和使用说明，例如：`账号标识 | 登录信息 | 使用说明`。
3. 一次最多 30 个，点击「加密导入赠送账号」。同一标识重复导入会跳过，大小写不区分。
4. 在「站点设置」填写自己的 Telegram 客服用户名，不带 `@`，使客户能够打开联系客服的链接。

后台不再次显示账号明文，导入前请自行妥善保管原资料。系统不会向 Telegram 自动注册账号。演示站只应导入测试资料，不要导入真实登录凭据。

每单创建时预留一个账号，付款成功后才显示给客户。创建、重复提交、订单查询都不能在未付款时获得账号内容。已分配账号仍保留原订单归属，不因取消或过期归还账号池，兼容旧版已展示过账号的订单。可赠送数量为零会暂停新下单，请关注库存和异常下单消耗。账号池有基础请求限流，但没有复杂反滥用或身份验证机制。

## 收款、发货与售后

- 微信、支付宝、USDT 均处于待接入状态，当前没有实际在线收款能力。
- 仅店主能登记已核实的线下到账，需填写唯一流水号及处理依据。登记后订单为已付款、未发货。
- 店主、运营和客服可在发货前补充收货信息。允许空地址下单不等于无需地址即可配送，请通过客服与客户确认。
- 店主或运营在订单详情中输入单号，确认已发货。单号需为 4–100 位字母、数字、空格、下划线或连字符，以字母或数字开头。
- 发货后收货资料锁定。在「收货与配送」中可选择「修正物流单号」，填写新单号和原因；录错发货状态可「撤销发货记录」。撤销只清空单号并回到已付款未发货，不恢复库存或更改到账记录。
- 工单支持回复、关闭与重新打开。未配置 Telegram 客服用户名时，客户仍可使用订单工单。
- 退款先在实际收款渠道完成，再由店主登记。登记不会发送资金，也不会自动增加库存；实物退回并验收后可在库存管理中按原因登记入库。
- 导出 CSV 仅包含当前订单页，不是全库备份；其中可能含收货资料，应妥善保管。

## 团队与账号

「员工与权限」可创建运营或客服账号，停用员工会立即撤销登录。点击右上角头像可修改密码。前台没有后台链接，后台地址为商城网址后加 `/admin`。

订单号与查询密钥就是客户的访问凭证。清理浏览器会删除本机订单记录，因此务必下载或另行保存；不要把密钥转发给无关人员。

## 客户登录与账号中心

商城右上角「登录」和「订单查询」在电脑和手机均有入口。

1. 真实商城：填写邮箱 → 获取验证码 → 输入邮件中的 6 位验证码 → 登录；首次验证自动注册。先完成 [邮箱配置](EMAIL.md)。
2. 当前演示站：点击「体验演示邮箱登录」，输入页面显示的演示验证码。此流程不发邮件，不验证任何真实邮箱。
3. 登录后购买的订单自动进入「我的订单」。点击即可查看付款、单号、付款后解锁的赠送账号并提交售后。
4. 以前免登录购买的订单，在账号中心「绑定以前的游客订单」填写订单号和查询密钥；绑定后可直接从账号内查看。
5. 在「个人与收货信息」保存常用资料；购物车里点击「使用常用信息」即可填入。各项仍可删除或留空。
6. 「账号安全」可退出所有设备。共享电脑上应退出登录并自行清理本机订单凭证；退出账号不会吊销已保存的独立查询密钥。

## 后台订单操作

- 点击订单号或「查看 / 处理」，可切换「订单与状态」「收货与配送」「售后与日志」。
- 「订单与状态」可登记收款、退款、关闭待付款订单、维护内部备注；内部备注不会发给客户。
- 合并发货：在「待发货」勾选 2–20 笔订单 → 「合并发货」 → 核对所选订单并填写原因。账号归属、收货人、联系方式和地址必须相同且完整。打开组内任一订单，可统一发货、修正或撤销单号；原有每单 20 元邮费及赠送账号各自保留。
- 解除合并：组内未发货时，在「收货与配送」点击「解除合并」。如果已经发货，先核实包裹情况，再撤销发货记录。仅软件记录改变，不会向快递公司撤单。
- 删除：店主在已完成发货或已关闭订单详情中选择「删除至回收站」，填写原因。通过列表「回收站」打开详情可恢复。客户查询、付款和赠送内容不会因删除消失。
- 订单筛选支持付款状态、配送状态，以及订单号、联系人、单号和合并组。CSV 仅导出当前页。
- 修改状态、配送、合并、删除和恢复均保留逐单日志。遇到「订单已更新」应刷新详情后重新核对。
- 「客户账号」可查看最近注册账号、验证情况和订单数量；店主可停用 / 恢复客户登录。停用不取消订单、不退款、不吊销订单查询凭证。

## 新增功能操作（2026-10-21）

- **其他商品免邮**：商品管理 → 新建 / 编辑商品 → 商品类型选「其他商品 · 单独购买免邮」→ 保存。前台「其他商品」栏目会显示；仅购买该类商品邮费 0 元，混合普通商品整单 20 元。旧订单金额保持原值。
- **订单通知**：客户结账选填联系邮箱。订单创建后发下单通知，确认付款后发购买成功通知；后台「订单邮件」查看状态及安全重试。没有填写邮箱的订单不发信。
- **提前充值**：客户登录 → 账户余额 → 申请充值。店主在后台「余额充值」核对实际收到的钱款，再填写真实收款流水及依据入账；未到账不要确认。站点设置可填写向客户展示的充值指引。
- **余额消费与退款**：客户打开本人订单 → 确认余额支付。余额不足会拒绝且不扣款。余额支付订单在后台订单详情可「退回账户余额」，真实增加原客户余额；其他付款仍需先线下退款再登记。
- **商品多图**：商品管理 → 编辑 → 上传或添加 HTTPS 图片链接。支持最多 8 张，箭头调整顺序，第一张为主图；保存商品后前台生效。上传未配置时按 DEPLOY.md 绑定 R2（BUCKET）。
