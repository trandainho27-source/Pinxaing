# 可选货源对接

后台「货源对接」保留 didipifa 的余额、商品同步、报价和确认采购适配。Pinxiang 没有继承旧站 API token、商品目录或采购记录。

如要启用，在服务器端配置 Secret `DIDIPIFA_API_TOKEN`。查看和同步不进行扣款。采购默认关闭，设置 `DIDIPIFA_PURCHASE_ENABLED=true` 后，仍需店主在后台核对商品、数量和报价，勾选并确认采购。

供应商库存不等于本店可售库存。只有采购成功、返回内容匹配并加密入库后，商品才有本地交付库存。网络超时保留原请求编号，避免盲目重买；不确定订单应先核对原采购。重复内容不会重复入库。

同步不会擅自覆盖已设置的零售价；供应商成本变化由店主核对。接口仅允许服务器端访问固定货源域名，Token 不发给顾客浏览器。采购和实际余额使用均未在本项目实测；现有测试使用模拟供应商响应。
